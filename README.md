# 💌 느린 우체통 (Slow Mailbox)
미래의 나에게 편지를 써두면, 정해둔 날짜에 다시 받아볼 수 있는 크롬 확장 프로그램입니다.

### 편지 쓰기
- 편지지는 크림·핑크 줄노트, 하늘색 모눈, 민트 도트, 크라프트지, 에어메일, 밤하늘 등에서 고를 수 있어요.
- 사진을 올리거나 직접 그린 그림을 폴라로이드처럼 붙일 수 있어요.
- 다 쓰면 성냥으로 초를 켜고, 왁스를 녹여서 문양이나 이니셜 도장을 찍을 수 있어.
- 상자에 담아 1달 뒤, 100일 뒤, 1년 뒤처럼 받을 날짜를 정해 보관해요.

- ### 베이킹
- 쿠키: 반죽 섞기 → 밀대로 밀기 → 곰·토끼·고양이 틀로 찍기 → 오븐에 굽기 → 초코펜, 아이싱, 스프링클로 꾸미기
- 레시피북을 보고 컵케이크나 홀케이크도 만들 수 있어요. 생크림 바르고 초도 꽂을 수 있습니다.
- 다 구운 건 선물 봉지에 넣어 편지와 같이 보내거나, 책상 위 접시에 두고 클릭해서 먹으면 돼요.

- ### 티타임
- 얼그레이, 캐모마일, 페퍼민트, 히비스커스 중에 고르고, 잔도 유리잔이나 머그잔으로 고를 수 있어요.
- 가스레인지에 주전자를 올려 물을 끓이고, 잔에 부은 다음 티백을 흔들어 우립니다.
- 레몬, 꿀, 각설탕을 넣거나 아이스로 만들 수도 있어요.

- ### 서랍과 다이어리
- 서랍에 편지지랑 공책 여러 권을 넣어둘 수 있어요.
- 공책은 줄노트, 모눈, 무지, 그리고 날씨와 그림을 같이 남기는 그림일기 모드가 있어요.
- 형광펜이나 스티커로 꾸밀 수 있고, 써둔 내용을 편지로 바로 옮길 수도 있습니다.

- ### 편지 받기
- 날짜가 되면 브라우저 알림과 함께 종소리가 울려요.
- 포장 테이프를 뜯고 실링을 깨서 열어보면 됩니다.
- 한국어와 영어를 지원해요.

- ## 설치 방법
- 1. 저장소를 클론하거나 ZIP으로 받아 압축을 풉니다.
```bash
   git clone https://github.com/사용자이름/slow-mailbox.git
```
2. 크롬 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위의 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 프로젝트 폴더를 선택합니다.
5. 툴바의 퍼즐 아이콘에서 느린 우체통을 눌러 시작하세요.
